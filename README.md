# DarkTech GPT Chat

Минимальный PHP/JS чат через Responses API Neurogate.

По умолчанию интерфейс работает как обычный текстовый чат. Для генерации или редактирования изображений включите режим `Картинки`.

Если запрос, загрузка референса или загрузка данных завершается ошибкой, сообщение с деталями появляется прямо в чате.

Настройки можно открыть из интерфейса. Они обновляют `config.php`: API URL, ключ, модель, таймаут, коэффициент токенов, пароль входа и системные промпты. Текущий API-ключ не выводится обратно в браузер; пустое поле ключа при сохранении оставляет прежнее значение.

Галерея загружает последние изображения порциями. По умолчанию показывается 36 картинок по 4 в ряд; значения меняются в настройках и хранятся в `gallery.page_size` и `gallery.columns`.

## Настройка

1. Откройте `config.php`.
2. Укажите `api.token`.
3. Замените `auth.password` или задайте `auth.password_hash`. Если оба значения пустые, экран входа отключается.
4. При необходимости измените `prompts.chat`, `prompts.image`, `api.model`, `image.output_format`, `image.size`, `usage.token_multiplier`, `gallery.page_size`, `gallery.columns`.
5. Убедитесь, что папки `data` и `img` доступны PHP на запись.

После загрузки на хостинг открывайте `index.php`.

Для Neurogate `api.stream` должен оставаться `true`: backend отклоняет нестриминговые Responses-запросы.

## Где хранятся данные

- История чатов: `data/chats.json`.
- Все изображения из режима `Картинки`: `img`.
- Новые файлы получают уникальные имена и не перезаписывают старые.
- Удаление файлов в интерфейсе не реализовано намеренно.

## Принятые допущения

- Backend использует `/v1/responses`, а не `/v1/images/generations`.
- В `model` указывается текстовая Responses-модель, например `gpt-5.5`.
- Обычный чат отправляет в API только текстовую историю текущего чата.
- Маски не реализованы: они требуют Files API, который в текущем backend может отсутствовать.
- Редактирование возможно через референс-картинки, отправленные как base64 data URL.
- Быстрые пропорции задают параметр `size` из `config.php`; если backend отклонит конкретный размер, поменяйте mapping в `image.ratios`.
- Токены считаются точно только если `/responses` возвращает поле `usage`; иначе интерфейс показывает, что данных нет.
- Отображаемые токены умножаются на `usage.token_multiplier`.

## Безопасность

Страница приложения закрыта паролем, если он задан в `config.php`. Для Apache добавлены `.htaccess`-файлы, которые закрывают `config.php`, `src` и `data`, а также запрещают выполнение PHP в `img`.

Если хостинг работает на Nginx, проверьте аналогичные правила в настройках сайта.
